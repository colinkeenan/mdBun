# mdBun
Serve .md files to html on localhost:3000
Just clone this repo, put 'mdBun.desktop' in '~/.local/share/applications', 'chmod +x md', and put 'md' in '/usr/local/bin'.
In a file browser, set the default application for opening .md files to 'mdBun'.
Run in terminal with 'md file.md' for whatever file.md you want, or run in GUI by clicking the .md file from the file browser.
